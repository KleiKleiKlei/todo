# Todo

Buat program yang menampilkan angka 1 sampai 100 secara berurutan, dengan aturan Buat aplikasi Todo List sederhana berbasis web dengan fitur CRUD dasar: menambah, melihat, mengedit, menandai tugas sebagai selesai, dan menghapus tugas.

## Run

Double-click `todo.html`. That's it really.
